    - 相比于原计划, 新计划在换班时会不断打乱巫恋的暖机进度, 进而减少4赤金贸易订单的出现, 从而起到增强但书、削弱龙舌兰的效果, 使得巫恋的作用更趋近于90效率

- 2025.09.14

- 2026.04.21
  - 新增 333 搓玉/全速龙门币 排班
    1. 适应 Maa 最新版的模块化任务: 考虑到实际每天 可获得的绿土 < 制造站消耗的绿土, 纯粹的 333 搓玉会有一段时间 源石碎片制造站 + 原石碎片贸易站 会出现空转的情况, 为了提高效率, 并简化操作, 特在此情况下执行 333纯龙门币 模式, 可自行根据当日贸易站情况进行 333-all-lmd 的切换, 求稳的话, 推荐在 ( 绿土 < 220 ) || ( 龙门币 < 126000 ) 时切换至 333纯龙门币模式
    2. 去除常态排班对 EMER 会使用到的干员的休息: 计算有点太麻烦, 且不同情况下可能有其他干员需要休息, 故不再在排班表内安排, EMER 终究为少数情况, 出现后使用排班, 自行休息对应干员即可
